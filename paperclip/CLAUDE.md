## Glossary (Paperclip vocabulary)

Preferred terms used across this project and its issues/discussions:

- **enterprise** — the Paperclip UI (the `ui/` React frontend).
- **crew** (also **the crew** / **a crew**) — the agents.
- **agents** — the agents themselves; interchangeable with **crew**.
- **Command** — the whole thing together: the company, the enterprise (UI), the custom skills, and the agents. Use this when referring to everything as a unit.
